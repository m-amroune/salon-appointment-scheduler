#  Project : Salon Appointment Scheduler

##  About the Project

**Objective** : Build a command-line appointment scheduling system for a salon using PostgreSQL and Bash. This project is part of FreeCodeCamp’s Relational Database Certification and is completed in a Linux environment with PostgreSQL and shell scripting.

##  Project Tasks

- Create a PostgreSQL database named `salon`
- Define tables for `customers`, `services`, and `appointments`
- Use appropriate constraints (`PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, etc.)
- Pre-populate the `services` table with at least three services
- Write a shell script that:
  - Lists available services
  - Prompts the user to select a service
  - Asks for the customer's phone number
  - Retrieves or creates the customer record
  - Prompts for an appointment time
  - Inserts the appointment into the database
  - Displays a confirmation message
- Handle invalid inputs and ensure smooth user interaction
- Pass all automated tests provided by CodeRoad
